# Recherche-Briefs (Agent Reach)

In diesem Verzeichnis landen die automatisch erzeugten **Internet-Recherche-
Briefs** von `scripts/agent_reach_research.py` (Agent-Reach-Integration,
12.09.2026). Ein Brief pro Lauf: `JJJJ-MM-TT-internet-recherche.md` (+ JSON-Beilage).

**Status eines Briefs: reine Signalsammlung.** Kein Treffer ist redaktionell
geprüft. Fakten (Preise, Gesetze, Fristen) dürfen erst nach menschlicher
Prüfung in kuratierte Dateien wie `data/aktuelle_entwicklungen.yaml`
übernommen werden – so verlangt es das KI-Redaktions-Statut (`KI-REDAKTION.md`).

Quellen des Briefs sind der kuratierte Themenplan
(`data/agent_reach/themenplan.yaml`) und die Kanalmatrix von
`agent-reach doctor` (im Brief dokumentiert). Details: `docs/ANLEITUNG-AGENT-REACH.md`.
