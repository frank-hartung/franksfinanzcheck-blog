## TEIL 1: Canva-Vorlagen-Anleitung (Pin-Grafiken im Branding)

### 1.1 Die Marken-Bausteine (aus deinem Masterplan)

| Element | Wert |
|---|---|
| **Format** | Vertikal 2:3 – **1000 × 1500 px** (oder 1080 × 1620 px) |
| **Hauptfarbe** | Smaragdgrün `#0E5A43` (Hintergrund) |
| **Dunkelgrün** | `#0A4634` (für Verläufe) |
| **Anthrazit** | `#2E2E33` (dunkle Akzente) |
| **Signalgelb** | `#FFB300` (CTA-Button) |
| **Weiß** | `#FFFFFF` (Haupttitel) |
| **Creme** | `#F0F5F2` (Subline) |
| **Titel-Font** | **Montserrat Bold** (fett, klar) |
| **Subline-Font** | **Playfair Display** (Serif, elegant) – kursiv |
| **CTA-Button** | Gelber Pill-Button (abgerundet), dunkler Text |

### 1.2 Canva-Setup (einmalig, 10 Minuten)

1. **canva.com** → kostenlos registrieren (oder Google-Konto)
2. Klick auf **„Design erstellen"** → **„Benutzerdefinierte Größe"** → `1000 × 1500 px` eingeben
3. **Markenfarben speichern:** Links im Menü → „Brand Kit" (kostenlos verfügbar) → Farben hinzufügen:
   - `#0E5A43` · `#0A4634` · `#2E2E33` · `#FFB300` · `#FFFFFF` · `#F0F5F2`
4. **Fonts hochladen (optional):** Google Fonts herunterladen (Montserrat-Bold.ttf, PlayfairDisplay-Italic.ttf) → Canva → „Upload" → „Schriftart hochladen" (im kostenlosen Plan möglich)
5. **Vorlage speichern:** Erstelle deine erste Pin-Grafik und klicke oben auf **„Vorlage speichern"** – damit hast du eine wiederverwendbare Markenvorlage

### 1.3 Die Pin-Vorlage (Schicht für Schicht)

```
┌─────────────────────────────┐
│  ████  (gelber Akzentbalken)│  ← oben, 60×12 px, #FFB300
│                             │
│                             │
│   Haupttitel (Montserrat    │  ← 1-2 Zeilen, 60-80 pt,
│   Bold, weiß, zentriert)    │     max. 6-8 Wörter
│                             │
│                             │
│  Untertitel (Playfair Italic│  ← 1 Zeile, 30-36 pt, #F0F5F2
│  kursiv, zentriert)         │
│                             │
│        [ Jetzt sparen ]     │  ← Gelber Pill-Button #FFB300
│                             │     Text #2E2E33, Montserrat Bold
│                             │
│   FranksFinanzcheck         │  ← Branding unten, 28-32 pt, #FFB300
└─────────────────────────────┘
```

**Regeln:**
- **Hintergrund:** Smaragdgrün – gern mit Verlauf (oben heller `#0E5A43`, unten dunkler `#0A4634`)
- **Titel:** 1–2 Zeilen, klar lesbar, Haupt-Keyword vorne (z. B. „Strom sparen: …")
- **Text-Overlay:** Pinterest liest den Text auf dem Bild – er sollte das Thema klar machen
- **Kein** zu viel Text – eine Pin-Grafik = eine Botschaft
- **Datei-Export:** PNG oder JPG, mind. 1000 × 1500 px

### 1.4 Text-Vorlagen für deine Pin-Beschreibungen

**Educational-Pin (EP):**
```
{TITEL mit Keyword}

{1-2 Sätze Nutzen, was der Leser lernt}
{1 Call-to-Action: "Tipps lesen" / "Jetzt sparen" / "Mehr erfahren"}

#Keyword1 #Keyword2 #Keyword3
```

**Transactional-Pin (TP):**
```
{Angebot/Titel mit Keyword}

{Kurz: Was man bekommt, z. B. "Vergleiche jetzt Tarife und sichere
dir Wechselprämien"}
#Anzeige

#Keyword1 #Keyword2 #Keyword3
```

## TEIL 2: Wöchentliche Pinterest-Checkliste

### 📅 Täglich (je 10–15 Minuten)

| Zeit | Aufgabe |
|---|---|
| **08:00** | Morgen-Pins veröffentlichen (aus Masterplan) |
| **08:10** | (Automatisch: Blog-Artikel erscheint – später als Pin nachpinnen) |
| **19:30** | Abend-Pins veröffentlichen |
| **19:40** | (Automatisch: 2. Blog-Artikel erscheint – später als Pin nachpinnen) |

**Kurz-Check beim Pinnen:**
- [ ] Titel mit Haupt-Keyword vorne?
- [ ] Beschreibung mit 3–6 Keywords + CTA?
- [ ] Alt-Text keyword-reich?
- [ ] Destination-URL = passender Blog-Artikel (nicht Startseite!)?
- [ ] Pin-Grafik im Branding (grün/gelb, vertikal)?

<!-- pagebreak -->
### 📆 Wöchentlich (montags, 30 Minuten)

- [ ] **Pinterest-Trends** checken: trends.pinterest.com → 3 Suchbegriffe für die Woche notieren
- [ ] **3–5 neue Pin-Grafiken** erstellen (Canva-Vorlage) aus den besten Blog-Artikeln
- [ ] **Neue Blog-Artikel der Woche** (14 Stück vom Bot) als Pins nachpinnen
- [ ] **Analytics auswerten:** Business-Hub → Analytics → „Outbound-Clicks": Welche Pins bringen Besucher auf den Blog?
- [ ] **Verlinkungsplan prüfen:** Sind alle Pins auf Artikel verlinkt? (Excel abgleichen)
- [ ] 1 **Idea Pin** erstellen (Reichweite): z. B. „3 Stromspar-Tipps in 30 Sekunden" (5 Slides)

### 📆 Monatlich (1 Stunde)

- [ ] **Best-Performer analysieren:** Top 5 Pins (Klicks/Saves) → Warum? → Muster auf neue Pins übertragen
- [ ] **Schwache Pins überarbeiten:** Neues Design, neuer Titel, neue Beschreibung (Fresh Pins)
- [ ] **Boards aufräumen:** Neue Boards anlegen, Pins sortieren, Board-Beschreibungen mit Keywords
- [ ] **Neue Themen-Ideen** aus Pinterest-Trends → für den Blog-Themenpool (`data/topics.yaml`)

## TEIL 3: Die 10 goldenen Regeln (auf einen Blick)

1. **Vertikal 2:3** – nie quadratisch oder horizontal
2. **Täglich pinnen** – gleichmäßig, nicht in Schüben
3. **Keyword im Titel** – vorne, nicht hinten
4. **3–6 Keywords** in der Beschreibung (natürlich, nicht gestopft)
5. **Passende Ziel-URL** – jeder Pin auf den passenden Artikel
6. **Fresh Pins** – regelmäßig neue Designs, auch für alte Themen
7. **Text-Overlay** – Text auf dem Bild (Pinterest liest ihn)
8. **CTA** – „Jetzt sparen", „Tipps lesen" etc.
9. **Idea Pins** für Reichweite, normale Pins für Traffic
10. **Analytics** – monatlich auswerten, was funktioniert

## Bonus: So nutzt du die Blog-Automatik für Pinterest

Dein Blog veröffentlicht **2 Artikel/Tag** automatisch. Daraus entstehen kostenlos neue Pins:

1. **Artikel lesen** (oder Titel + Kernaussagen ansehen)
2. **Canva-Vorlage öffnen** → Titel + Untertitel anpassen
3. **Exportieren** → auf Pinterest pinnen mit Artikel-URL als Destination
4. Fertig – jeder Blog-Artikel wird so auch ein Pinterest-Asset

**Kreislauf:** Pinterest-Pin → Blog-Artikel → Affiliate-Link → (neuer Artikel vom Bot) → neuer Pin → ...
